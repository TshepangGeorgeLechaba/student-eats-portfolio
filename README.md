# Student Eats e-Portfolio

**Course:** Diploma in ICT (Multimedia)  
**Subject:** Project Presentation 3 (PRP370S / PRP372S)  
**Assessment:** Assessment 2 — Digital Portfolio  
**Institution:** Cape Peninsula University of Technology (CPUT)

## 📌 Overview
Welcome to the e-Portfolio for **Student Eats** — a digital marketplace connecting CPUT residence food vendors with student buyers. This portfolio documents our team's Agile development process, team charter, user stories, product backlogs, and sprint logs.
